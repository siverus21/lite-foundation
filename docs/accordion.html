Component

Accordion

Раскрывающиеся секции на native <details>/<summary>. Работает даже без JS; модуль добавляет режим «только одна панель» и единообразие a11y.

styles.accordion scripts.accordion

Когда использовать

Подходит
  • FAQ, длинные описания, «показать детали»
  • Когда важно, чтобы контент индексировался и работал без JS
Не путать с
  • Accordion menu — навигация, не контентные панели
  • Tabs — взаимоисключающие панели на одном уровне просмотра

Пример

По умолчанию открыта одна панель. Несколько сразу: data-multi-expand="true" на корне.

Accordion 1

Panel 1 content.

Accordion 2

Panel 2 content.

Accordion 3

Panel 3 content.

<div class="accordion" data-accordion>
  <details class="accordion-item" open>
    <summary class="accordion-title">Accordion 1</summary>
    <div class="accordion-content"><p>Panel 1</p></div>
  </details>
  <details class="accordion-item">
    <summary class="accordion-title">Accordion 2</summary>
    <div class="accordion-content"><p>Panel 2</p></div>
  </details>
</div>

<!-- несколько открытых: data-multi-expand="true" -->
