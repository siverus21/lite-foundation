Modal

Диалог поверх страницы на native <dialog>: фокус-трап и Esc даёт браузер, модуль добавляет открытие по data-атрибутам и scroll-lock.

styles.modal scripts.modal

Когда использовать

Подходит
  • Подтверждение удаления, короткие формы, превью
  • Контент, который должен блокировать остальную страницу
Не подходит
  • Мобильная навигация — бери Off-canvas
  • Неблокирующие подсказки — Dropdown / Tooltip

Разметка и API

  • Открыть: data-dialog-open="id" на кнопке
  • Закрыть: data-dialog-close, Esc, клик по backdrop (dialog сам)
  • Класс на диалоге: modal, уникальный id

Native dialog

Закрытие: крестик, Esc или клик по backdrop.

 
<button type="button" class="button" data-dialog-open="docsModal">Open</button>

<dialog class="modal" id="docsModal">
  <button class="close-button" type="button" data-dialog-close aria-label="Close">
    <span aria-hidden="true">&times;</span>
  </button>
  <h3 class="modal__title">Title</h3>
  <p>Content</p>
  <button type="button" class="button" data-dialog-close>Close</button>
</dialog>
