Component

Button

Базовый контрол действия: отправка формы, открытие modal/off-canvas, вторичные действия. Только CSS — JS не требуется.

styles.button

Когда использовать

Подходит
  • CTA в hero, тулбары, подтверждения в формах
  • Триггеры для modal / dropdown / off-canvas (type="button")
  • Группы переключателей визуального выбора (button-group)
Не подходит
  • Навигация по сайту — лучше <a> без класса button или обычная ссылка в меню
  • Переключатели on/off — см. switch; кастомные checkbox/radio — тоже на Forms

Варианты

Цвет = семантический статус; hollow/clear — вторичный акцент без заливки.

<button type="button" class="button primary">Primary</button>
<button type="button" class="button hollow">Hollow</button>
<button type="button" class="button expanded primary">Expanded</button>

Button group

Склейка кнопок в один визуальный блок (фильтры, сегменты).

One Two Three 
<div class="button-group">
  <a class="button">One</a>
  <a class="button">Two</a>
  <a class="button">Three</a>
</div>
