Component

Tabs

Переключение панелей на одной странице с ролями WAI-ARIA и навигацией стрелками. URL не меняется — для deep-link лучше отдельные якоря или роутер.

styles.tabs scripts.tabs

Когда использовать

Подходит
  • Карточка товара: описание / характеристики / отзывы
  • Настройки с несколькими равнозначными секциями
Не подходит
  • Длинный FAQ — Accordion читабельнее
  • Шаги мастера с прогрессом — отдельный wizard / отдельные URL

Разметка

Связка: data-tabs + id списка и data-tabs-content="тот-же-id". У tab — aria-controls, у panel — aria-labelledby.
