# scss/critical/

Временные / критичные правки стилей, которые:

- **подключаются последними** (перебивают компоненты);
- **не проверяются** `lint:tokens` (можно писать `#hex`, `z-index: 99` и т.д.);
- **напоминают о себе** на `npm run start` / `npm run build`, пока здесь лежат partials.

## Как пользоваться

1. Добавь файл: `scss/critical/_hotfix-modal.scss` (пустой placeholder не считается)
2. Перезапусти Vite / сохрани — `_index.scss` подхватит **непустые** partials
3. Как только можно — перенеси правила в нормальный компонент + токены `--lf-*` и удали файл отсюда

Не коммить сюда постоянный дизайн — папка для срочных патчей.
